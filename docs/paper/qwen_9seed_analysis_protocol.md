# Qwen2.5-14B Nine-Seed Analysis Protocol

## Scope and inferential stance

This analysis is restricted to the nine files whose names contain `simulation_qwen2.5-14b_Full_scnldf_sh1_ldf1` and the seed identifiers 1 through 9. The files are treated as the primary replication units. Each file contains repeated observations of agents and rounds, but those observations are not assumed to be independent replications of the underlying stochastic experiment. All cross-condition claims are therefore withheld: this is a multi-seed analysis of one full treatment configuration, not a randomized comparison of climate shocks, LDF availability, or democracy against a control condition.

The analysis distinguishes three levels of claim. A direct descriptive claim is supported by the observed Qwen runs, including the direction and size of run-level summaries. An associational claim describes a relationship among logged variables, such as a post-shock change in contribution or the association between reputation and cooperation. A causal claim requires a credible counterfactual, a control condition, and assumptions about treatment timing and interference; unless those conditions are established in the source and data, the report uses associational language.

## Analysis hierarchy

The extraction layer will preserve the raw round records and produce tidy tables at four levels. The run table will contain one row per seed and summarize treatment configuration, completeness, and terminal outcomes. The round table will contain one row per seed and round with aggregate contributions, cooperation, inequality, LDF flows, shocks, and governance events. The agent-round table will contain one row per seed, round, and agent, including group membership, contribution, payoff, wealth, reputation, beliefs, sanctions, rewards, and available reasoning text. Event tables will flatten proposals, votes, transfers, punishments, rewards, gossip, and constitutional changes into explicit event records. Every derived table will retain the source filename and evidence identifiers so that a reported number can be traced back to a raw record.

## Outcomes and derived measures

The primary behavioral outcome is the proportion of eligible agent-round observations with a positive contribution, accompanied by the contribution amount and contribution relative to the reconstructed pre-decision wealth budget. The JSON field named `cooperation_rate` is retained as a source-defined diagnostic: the implementation calculates it as the mean of contribution divided by the post-payoff end-of-round wealth cap, so it is not the positive-contributor rate and is not used as the primary cooperation outcome. Secondary outcomes include the mean and median contribution, the share of zero-contribution observations, within-run inequality in contribution and wealth, group-specific cooperation, and the persistence or recovery of cooperation after the logged shock. The report will not collapse these measures into a single cooperation score: a mean contribution can rise because a few agents contribute more, whereas a cooperation rate can fall because a previously cooperative agent becomes a free rider.

LDF outcomes will distinguish contributions into the fund, pool balances, payouts, recipients, transfer amounts, and the timing of insolvency or depletion. “Coverage” will be defined explicitly in the extraction code rather than inferred from the word coverage. Governance outcomes will distinguish the existence of a proposal, votes, adoption, enforcement, sanctions, rewards, and constitutional change. Reputation and theory-of-mind variables will be analyzed as logged mechanisms or correlates, not as proof that an internal cognitive mechanism caused cooperation.

## Uncertainty and robustness

The main uncertainty estimate is a seed-level nonparametric bootstrap: resample the nine run identifiers with replacement, recompute the estimand on each resample, and report percentile confidence intervals. For paired pre/post or within-run comparisons, the same resampling is performed on run-level paired differences. Agent-round observations will also be summarized with run-clustered standard errors or a multilevel model with a random run intercept where the sample size and design justify it. Naive agent-level confidence intervals will not be presented as the primary uncertainty estimate because they would overstate replication.

Robustness checks will vary defensible choices rather than search for a preferred result: alternate cooperation windows around the shock, median versus trimmed summaries, leave-one-seed-out estimates, exclusion of malformed or incomplete records with an explicit denominator, and alternative definitions of proportional contribution where the source permits. The final report will show the sensitivity of substantive conclusions to these choices, especially when an apparent effect is driven by one run.

## Qualitative and language analysis

Reasoning and event text will be analyzed descriptively and with reproducible lexical summaries. Recurrent terms and event motifs may illuminate how agents describe reciprocity, climate risk, fairness, and enforcement. Lexical frequencies are not treated as psychological measurements, and topic labels will be accompanied by counts, denominators, representative evidence IDs, and a manual review of the underlying text. Any second coding pass will preserve the original text and coding rule so that disagreements can be audited.

## Reproducibility and reporting

All derived tables, figures, machine-readable summaries, and figures' source tables are written under `analysis_outputs/qwen2_5_14b_9seed/`. The extraction and analysis code lives under `src/analysis/qwen_9seed/`, is runnable with the `ml` environment, and includes a manifest containing input hashes, row counts, software versions, and command lines. The final Markdown report links to those artifacts and uses paragraphs for interpretation, with tables reserved for exact values and compact visual summaries.

## Implementation-specific safeguards added after source review

Climate/LDF mode hard-routes developed agents to SI and developing agents to SFI, so the analysis labels role comparisons as assigned-role heterogeneity rather than institution effects. The LDF deposit is the same Stage-1 contribution, so it is not counted as a second payment. The raw `cooperation_rate` field is retained as an end-wealth intensity diagnostic, while the primary intensity measure uses the reconstructed pre-decision cap. Shocks at rounds 5 and 10 are analyzed as scheduled discontinuities with responses beginning at t+1 because contributions precede the shock; these rounds also coincide with constitutional sessions. ToM/gossip exposure is reconstructed as certain/possible bounds because the live bulletin and completion order are not serialized. Stage-2 parser metadata is analyzed alongside final allocations because `parsing_failures` is zero even when auto-fitting and fallbacks occur. Democracy results are described as Oracle-guided plurality adaptation, and model provenance is limited to the filename alias because the result files do not encode checkpoint, quantization, or inference-server metadata.
